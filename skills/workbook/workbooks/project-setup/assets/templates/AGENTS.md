## 项目结构

| 文档 | 固定路径 | 用途与读取时机 |
| --- | --- | --- |
| PRODUCT | `PRODUCT.md` | 产品定位、目标用户、场景、范围与全局业务术语；讨论产品需求或业务概念时读取 |
| DEVTECH | `DEVTECH.md` | 技术选择、工程组织、宏观职责与全局技术术语；设计技术方案或实现涉及全局约束时读取对应章节 |
| DESIGN | `DESIGN.md` | 视觉与交互规范；设计或实现界面、视觉表现时读取 |
| ARD | `docs/ARD.md` | 架构边界、Module / Feature 结构；设计或实现涉及模块边界时读取对应部分 |

| 路径 | 用途与读取时机 |
| --- | --- |
| `docs/implementation-specs/` | Implementation Spec（含模块级技术术语）；设计或实现对应功能时读取 |
| `docs/plans/` | Plan 仓库 |
| `docs/knowledge/decisions/` | 项目宏观决策记录与索引；追溯设计选择、约束与取舍理由时读取 |
| `docs/knowledge/retrospectives/` | 项目复盘与关键变更记录；查证历史故障与演化背景时读取 |
| `docs/research/` | 研究草稿；仅在探索特定问题或设计方案定稿时读取 |
| `docs/references/` | 外部参考资料；查证对应设计或技术依据时读取 |
| `docs/archives/` | 退役资料归档 |

- 严禁修改非当前任务所属或已完成（`done`）的历史 Plan、Task、交付证据与审核记录。
- 历史 Plan 内的旧引用、旧签名与当时快照属于不可篡改的历史审计证据，不得逆向同步。
