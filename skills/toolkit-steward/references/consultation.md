# 咨询工作指引

`toolkit-steward` 负责解答 Trigrams toolkit 体系问题、指导能力选型与任务分流、诊断项目就绪状态，并引导项目接入与扩展管理。

## 即时诊断与任务分流

针对项目状态诊断与常规任务分流，直接查询当前环境与可用方法，不必通读全部专题资料：

1. **检查当前项目与计划状态**：
   - 优先检查用户指定材料、项目入口与 `.agents/harness.json`。仅在问题涉及登记身份、关系或 Plan 进度时，按需调用 `project-state` 或 `plan-toolkit` 只读查询。
   - 命令缺失、查询失败，或遇到缺少身份、快照缺失、快照过期时，将其记录为取证缺口（写明对象、结果与受影响的诊断范围），不自行补写或同步。
2. **推荐或加载工作方法**：
   - 调用 `workbook` Skill（或通过 `handbook` 查询可用分类与条目），按任务目标匹配适用的 workbook，列出推荐条目或方法缺口。
3. **输出诊断结论**：给出已核实的客观事实、受阻原因与明确的下一步建议。

## 架构咨询与资料检索

查询工具包架构设计、组件职责、数据契约、项目接入或全局环境配置时，先复用来源明确且仍适用的既有结论；超出已有证据时，按问题主题选择对应文档（跨主题问题可组合读取）：

| 查询主题 | 参考文档 |
| --- | --- |
| 架构设计、组件关系、principle 机制与项目知识分层 | [architecture.md](architecture.md) |
| Skill、公共工具职责与工作流协作分工 | [capabilities.md](capabilities.md) |
| 数据事实来源、状态机门禁与交接契约 | [contracts.md](contracts.md) |
| 项目首次接入、状态重建及扩展增补、同步与移除 | [project-integration.md](project-integration.md) |
| 全局 CLI、core Skill 与外部依赖的安装与恢复 | [deployment.md](deployment.md) |

资料不可读时，报告受影响的咨询范围，仅答复已有证据支持的部分。

## 职责边界

- **咨询与分流**：架构说明、方案选型与现状诊断按本指引完成。
- **工作流协同**：用户明确调用其他专用执行 Skill 时，遵循对应任务流程与分工。
- **机制说明独立**：对话中的机制说明与原理问答可独立使用已有文稿，不依赖项目初始化状态或工具查询，在未接入项目中保持可用。
