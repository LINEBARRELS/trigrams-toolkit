# 显式声明 TypeScript 模块边界与结果契约

定义 TypeScript／JavaScript 模块入口、外部数据接收签名与异步失败返回时，应严守模块边界并遵守声明期规模口径：

- **外部未验证数据：** 接收未验证外部数据的签名应使用 `unknown`，经校验函数转换为内部强类型后再进入业务代码。
- **模块公开导出：** 模块公开 API 从入口文件导出，导出项宜逐个列出；外部代码不应直接深层导入模块内部实现文件。
- **失败与异步签名：** 可预期的失败返回 `undefined` 或结果联合类型（如 `{ ok: true; value: T } | { ok: false; error: E }`）；异步函数显式标注返回 `Promise<T>`，可取消操作接收 `AbortSignal`。
- **声明规模口径：** 解构参数、剩余参数（`...rest`）各计 1，TypeScript 的 `this` 伪参数不计；对象参数应表达共同概念，不应用 `options` 大包隐藏无关参数；文件行数超限时检查是否混入内部细节或多个复杂组件。
