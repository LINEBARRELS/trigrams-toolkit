# 收窄 TypeScript 类型并穷尽检查可辨识联合

编写 TypeScript／JavaScript 函数体分支与类型转换时，应依靠控制流收窄与编译期穷尽检查，并遵守实现期规模口径：

- **类型收窄与守卫：** 使用控制流检查证明类型，跨处复用的复杂结构判别宜封装为类型谓词（`x is T`）或断言函数（`asserts x is T`）；不应用 `any`、双重断言（`as unknown as T`）或非空断言 `!` 代替缺失的运行时检查，牢记 `as` 不执行运行时校验。
- **穷尽检查：** 分派可辨识联合时，在 `switch` 或条件链默认分支将值赋给 `never` 类型，使新增但遗漏处理的变体在编译期报错。
- **实现规模口径：** 有效行计入仅含括号的行，超限时检查纯计算、状态修改与 I/O 是否混杂；嵌套深度以顶层函数体为 0，每嵌套一层 `if`、循环或 `switch` 加 1，同级 `else if`／`case` 及 `try`／`catch`／`finally` 不叠加，超限时用守卫语句或分派表展平。
