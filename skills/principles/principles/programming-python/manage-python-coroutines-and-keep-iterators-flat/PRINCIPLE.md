# 管控 Python 协程生命周期并保持迭代平坦

编写 Python 异步任务、迭代逻辑与函数体控制流时，应确保协程受控、避免推导式过载并遵守实现期规模口径：

- **协程与并发：** 协程应被显式等待或交给明确管理者（Python 3.11+ 并发任务可用 `TaskGroup`）；取消后完成必要清理并通常继续传播 `CancelledError`；异步函数内不直接执行长时间同步阻塞操作。
- **迭代器与推导式：** 区分可重复遍历的集合与一次性消耗的迭代器；不应用复杂推导式承载多阶段流程或副作用。
- **实现规模口径：** 有效行统计不计装饰器，超限时检查是否混合了不同抽象层次的步骤；嵌套深度以顶层函数体为 0，每嵌套一层 `if`、`for`、`while`、`match` 加 1，推导式中每个 `for` 和 `if` 子句各计 1 层，同级 `elif`／`case` 及 `with`、`try`／`except`／`finally` 不叠加，超限时用守卫语句展平。
