# 使用显式类型建模 Python 数据与协议

声明 Python 类、数据结构、多态接口与常量时，应使用显式类型注解与不可变结构表达领域契约：

- **类型注解：** 公开函数和模块入口应写完整的类型注解；注解、`TypedDict` 和 `NewType` 不提供运行时校验，外部输入数据应另行校验。
- **数据类型：** 不可变记录使用 `@dataclass(frozen=True)` 或 `NamedTuple`；描述外部字典结构使用 `TypedDict`。
- **领域原始值：** 底层类型相同但业务含义不同的值用 `NewType` 区分；有取值约束的值用 `dataclass` 声明并在 `__post_init__` 中校验。
- **抽象与多态：** 结构化多态使用 `Protocol`，需要共享实现时使用 `ABC`，仅替换单个行为时直接传入函数并标注 `Callable`。
- **常量与枚举：** 模块级常量使用全大写名称并标注 `Final`；有限类别使用 `Enum`（Python 3.11+ 字符串枚举使用 `StrEnum`）。
