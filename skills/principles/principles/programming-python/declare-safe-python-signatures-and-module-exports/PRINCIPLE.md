# 声明安全的 Python 函数签名与模块导出

定义 Python 函数签名、默认参数、模块导出与失败返回时，应避免可变默认状态并明确模块边界：

- **默认参数：** 不应使用可变对象作默认参数；应使用 `None` 或专用哨兵对象，并在函数体内创建可变实例。
- **可见性与导出：** 以单下划线 `_` 开头的名称表示内部实现；包的公开 API 在 `__init__.py` 中显式导出并用 `__all__` 列出。
- **失败语义：** 可预期的“未找到”返回 `None` 且签名标为 `T | None`；违反调用前提时抛出 `ValueError` 或 `TypeError`；项目自定义异常应继承统一的基异常。
- **声明规模口径：** 参数计数不计绑定接收者 `self`／`cls`，关键字参数、`*args`、`**kwargs` 各计 1；公开函数不宜用键集合不明确的 `**kwargs` 隐藏实际参数；文件行数超限时检查独立职责与内部模块切分。
