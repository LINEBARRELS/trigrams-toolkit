# 区分 Python 缺失值并规范管理上下文与异常链

编写 Python 函数体处理空值、外部资源与异常时，应精确区分业务假值并保持资源释放与异常链完整：

- **缺失值判别：** `None`、空集合和零值应按业务语义严格区分；判断缺失时显式写 `if value is None`，仅在确实判断布尔真值时才写 `if value`。
- **上下文资源管理：** 文件、连接、锁等资源统一使用 `with` 或 `async with` 上下文管理器管理生命周期。
- **异常捕获与转换：** 只捕获当前边界能够处理的具体异常类型，不应用裸 `except` 或宽泛吞掉进程退出与协程取消；转换异常语义时使用 `raise NewError(...) from err` 保留原始原因链。
