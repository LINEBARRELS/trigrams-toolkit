# 在源码中标识 Stub 并维护交接注释

负责 Stub 安装与装填的 Task 应在源码中维护可搜索的 Stub 标识与交接说明，使接手者能直接沿源码定位并完成实现。

源码标识与交接注释应遵循以下要求：
- **声明标识：** 安装 Task 在新增类、函数、独立常量、枚举及工具函数声明处添加 `@plan-stub {plan-name}-{stub-id}` 注释（`plan-name` 取 Plan 目录名，`stub-id` 取 `installs` 编号，如 `@plan-stub inventory-v2-S01`）；同一主体属多个 Stub 时分别标识。
- **框架内交接注释：** 安装者在声明或待实现位置写明待实现的逻辑步骤或伪代码、输入输出约束、关键边界与依赖（如：`// 待装填：读取库存 -> 校验可用数量 -> 原子扣减；库存不足返回约定失败结果`）。
- **装填后维护：** 装填者完成实现后应保留 `@plan-stub` 标识供长期检索，同时按实际实现更新说明，清除已失效的伪代码与待办。
