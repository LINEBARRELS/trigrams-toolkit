# 先确定框架再填充逻辑

规划与实现编程工作时，应先确定本次范围内的框架契约，再编写具体逻辑。

框架构建与阶段编排应满足以下要求：
- 先复用并核对既有框架，再补齐本次所需的类、函数签名、常量、枚举及工具函数，明确职责、依赖方向、输入输出和失败语义。
- 涉及跨模块契约或复杂骨架时，可将编程 Stub 按两阶段交接：先安装框架契约并完成安装验收，再装填具体逻辑与行为验收；该两阶段约束应在规划阶段写入 Plan 正文。
- 简单改动或单阶段内完成的编程工作，同样应在动笔写逻辑前先确立框架契约，再填充具体实现。
