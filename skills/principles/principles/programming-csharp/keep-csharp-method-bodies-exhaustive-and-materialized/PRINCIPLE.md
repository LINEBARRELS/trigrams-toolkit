# 保持 C# 方法体分派穷尽与集合物化

编写 C# 方法体内部逻辑时，应使用模式匹配与穷尽分派、显式处理空值、物化多次遍历集合，并遵守实现期规模口径：

- **空值断言：** 不应用 `!` 掩盖未知可空状态；确需断言非空时，在该位置写明不可能为空的依据。
- **模式匹配与穷尽分派：** 有限状态或闭合 `record` 变体分派宜用 `switch` 表达式，除非默认处理是有意的，不应用 `_` 分支静默吞掉新增变体；复合条件与序列拆解宜用属性模式、关系模式与列表模式（如 `is { Amount: > 0 }`、`[var head, .. var tail]`）一次完成判空、类型收窄与字段提取，替代多层 `if`、强制转换 `(Sub)x` 或手写下标切片。
- **集合物化：** 注意 LINQ 的延迟执行与重复枚举成本；多次遍历的结果应先用 `ToList()` 或 `ToArray()` 物化。
- **实现规模口径：** 有效行计入仅含括号的行，超限时检查是否混杂了不同抽象层次的步骤；嵌套深度以顶层方法体为 0，每嵌套一层 `if`、循环或 `switch` 加 1，同级 `else if`／`case` 及 `using`、`try`／`catch`／`finally`、`lock` 块不叠加，超限时用守卫语句或模式匹配展平。
