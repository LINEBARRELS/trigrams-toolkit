# 传递 C# 异步取消并明确管理资源与异常

实现 C# 异步链路、资源生命周期与异常边界时，应保持非阻塞执行、完整传递取消并严格对齐资源所有权：

- **异步链路：** 异步调用全程使用 `await`，不应使用 `.Result` 或 `.Wait()` 同步阻塞线程。
- **取消传播：** 沿调用链传递 `CancellationToken`；取消不应被转换为成功结果，操作提交后能否取消按操作语义决定。
- **资源所有权：** 自己拥有的资源用 `using`、`await using` 或明确释放流程管理；借用的资源不擅自释放；长生命周期的事件订阅应在拥有者释放时解除。
- **异常边界：** 只在能恢复或转换语义的边界捕获异常；重新抛出用 `throw;` 保留原始堆栈，转换异常时将原异常作为 `innerException` 传入。
