# ARD 单页报告

遵循[报告通用指引](report-guide.md)，阅读维护后的 ARD 与项目 DEVTECH，沿用项目约定的文档路径，整合 `tree` 与 `flow` 图生成单页报告。页首概括架构设计结论，修订时说明本次变化。

## 架构树

生成 `tree` 图（子节点较多时使用 `tree list`），以项目为根，按 `Architecture Layer → Module → Feature` 展开。沿用 ARD 中的名称、归属与框架模块 `（Arch）` 标注，节点用 `label | note` 简述职责。修订时使用变更标记标出新增、移除或修改的项。

## 依赖与边界

生成 `flow` 图，以 ARD 的架构层级与 Module 职责为骨架，结合 DEVTECH 中的宏观职责、依赖方向、所有权与跨层入口，展示系统协作关系。以 Module 为主体，用 `group` 标明架构层级或职责边界，按文档展开参与跨模块协作的 Feature 与外部依赖，在连线上标明调用、依赖、读写等关系方向与含义。

必要关系与影响行为的条件保留在节点或连线上，补充解释收入表格或 `callout` 面板。模块与连线较多时按关注点拆分为多张 `flow` 图，避免连线过度交叉。修订时使用变更标记标出变更涉及的边界与关系。
