# doc-polish

处理美术与文本创作相关内容时，不读取语言规范，禁止使用标准语言规范约束创作表达，以免破坏审美与叙事表达力。

完整阅读[技术文档标准语言规范](references/技术文档标准语言规范.md)。同一上下文已读、版本未变且当前用途仍适用时，直接复用，不必每次动笔前重读。
编写文档时可按约 80% 的程度遵守规范，以保留表达自然度。
收敛的是表达，不是具体内容，事实内容不能被破坏。
维护已有文档时，保留有效内容、既有决策和不确定性；内容变化以当前任务及项目事实为准。
