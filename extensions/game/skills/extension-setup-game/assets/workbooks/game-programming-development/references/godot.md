# Godot 运行与证据方法

## 确定运行入口

核对工程 `project.godot`、引擎版本与被审代码或构建版本，明确主场景、独立试玩场景、启动参数与工作目录，将启动命令交付给后续执行者。

规则验证选用直达目标状态的场景。画面、输入或时序验证采用实际图形运行环境；无窗口（headless）模式仅用于日志、状态计算与自动化断言验收。

## 复现与证据采集

1. 说明启动场景、存档或初始数据、输入顺序与观察点；涉及随机性时固定种子。
2. 逐步确认场景加载、状态触发、结算与反馈，区分规则结算与表现结果。
3. 按 `game:principle:runtime-evidence/choose-evidence-that-can-support-the-claim` 采集截图、录屏、日志或性能指标并链接至验收结论；跨 Task 交接时附上可运行成果位置与复现步骤。
