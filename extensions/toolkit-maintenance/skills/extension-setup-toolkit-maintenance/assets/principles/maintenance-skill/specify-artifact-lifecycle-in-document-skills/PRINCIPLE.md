# 在文档类 Skill 中明确成果路径与维护生命周期

涉及新建、更新或归档工具包架构文档（`docs/`）的 Skill，应完整定义文档定位与生命周期交接，不能只写“保存到某目录”。

文档维护说明应包含以下要素：
- 明确路径基准、目录结构与命名规则。公共 CLI 的业务命令以目标项目根为工作目录。文稿路径优先沿用项目既有约定，无约定时采用文档体系默认路径。
- 说明文档的职责边界、新建与复用已有文稿的判断条件，以及后续更新与维护交接方式。
- 涉及身份登记、引用回写、快照状态同步或旧状态归档时，应指明适用的公共契约与操作工具入口（如 `project-state`、`plan-toolkit`、`harness-install`），共享规则通过唯一正文按需引用。
