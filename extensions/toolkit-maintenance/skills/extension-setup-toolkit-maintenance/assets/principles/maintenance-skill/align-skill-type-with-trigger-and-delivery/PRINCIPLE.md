# 对齐 Skill 主类型与触发及交付要求

Skill 的 `description`、主类型声明（`metadata.harness-toolkit-type`）与入口正文应指向一致的职责边界和交付物。

按主类型核对核心要求：
- `content-loading`：按语言、场景或模式分流资料，区分强制要求、推荐做法与示例，明确应用边界。
- `tool`：明确操作对象、工具入口、输入、运行条件与结果判据；状态变更应具备写入保护与恢复机制。
- `quality-review`：明确审核范围、判断标准、例外与证据要求，区分事实、测量、推断与建议。
- `workflow`：明确启动、流转、返工或归档条件与状态交接，避免流程死锁；只固化有正式依据的必要流程，复杂分支与循环退出条件应使用 Mermaid 图或伪代码表达。

`description` 应精炼陈述能力与触发时机，避免堆砌防御式排除描述；类型声明与正文冲突时视为缺陷。
