# 按模式中立与规划转化要求组织 workbook 章节与配套资源

`WORKBOOK.md` 应保持 Plan 模式中立，提供结构完整、可直接指导执行或由 `to-plan` 转化为任意模式 Plan 的工作方法，并按职责边界组织元数据与配套文件。

章节与资源组织应遵循以下标准：
- 正文包含“适用与输入、必要工作流程、工序切分与交接、产出与验收”四个基础章节；不耦合特定 Plan 模式的目录或调度语法。
  - “必要工作流程”章节不应过度细化，只做工作执行中的必要行为描述。
- 方法应区分已验证做法与候选方案，按真实依赖排列工序；执行者可直接依据方法开展工作，或由 `to-plan` 据此将具体路径、原则 ID、Stub 边界与验收约束落盘到 Plan。
- YAML 头的 `name`、`description` 与目录 `scope` 应指向一致的工作领域并与同类 `workbook` 形成区分；`includes` 仅声明每次执行均必读的原则，条件依据放入 `references/`，模板放入 `assets/`，私有脚本放入 `scripts/`。
- 可按需追加一个“工作约束”章节，记录必要的执行禁令与行为约束。
