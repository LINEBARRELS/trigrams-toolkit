# 按任务相关性选择并组合原则

使用原则时应根据当前任务的具体决策点，先从分类索引筛选相关条目，再加载并组合所需的完整正文。

选择与编排读取步骤时应遵循以下要求：
- 执行任务前先按相关 `scope` 查看 `resourceId` 与 `description`，只加载对当前决策有实际约束力的原则，不应无条件全量加载整个 `scope` 下的所有条目。
- 每次执行固定工作流均不可缺少的底线判断，由对应 `workbook` 的 `includes` 声明必读；仅在特定分支、对象或改动类型下生效的原则，在工作方法中写明触发条件，按需选取。
- 多条选中原则共同作用于同一任务时，核对各自适用条件；若出现冲突，列明来源与影响供裁决。
