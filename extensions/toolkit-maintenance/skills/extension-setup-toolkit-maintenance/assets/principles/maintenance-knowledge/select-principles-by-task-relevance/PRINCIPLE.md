# 按任务相关性选择并组合原则

使用原则时应根据当前任务的具体决策点，先按 `scope` 浏览 `resourceId` 与 `description` 筛选相关条目，再加载完整正文，不应无条件全量倾倒。

配置原则加载时机应区分三层：
- **必读底线**：每次执行某 `workbook` 均不可缺少的底线判断，由该 `workbook` 的 `includes` 声明自动随附。
- **按需路由**：仅在特定材料、语言、分支或审核节点生效的原则，在 `WORKBOOK.md` 的 `<exec-rule>`、`<review-rule>` 或具体任务条目中写明触发条件与对应 `scope`/ID，按需加载。
- **冲突处理**：多条选中原则共同作用于同一任务时，核对各自适用条件；若出现冲突，列明来源与影响供裁决。
