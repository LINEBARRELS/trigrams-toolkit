# 保持原则可独立应用

一条 `principle` 应只承载一个可独立应用的判断，使调用方加载单条原则即可完成对应决策。

划分与审核原则边界时应满足以下要求：
- 能分别适用于不同任务或不同工作阶段的判断，应拆分为独立的原则目录分别维护，不应将多项正交规则打包在同一个主题入口下。
- 作出该判断所需的适用条件、核心理由与必要例外应保存在同一篇正文内，不通过 `includes` 隐式拉取其他原则。
- 同一规则只保留一个维护源；多处原则出现相同要求时应合并到责任最匹配的唯一入口，仅作为某条规则成立前提的限定条件应留在该规则正文内。
