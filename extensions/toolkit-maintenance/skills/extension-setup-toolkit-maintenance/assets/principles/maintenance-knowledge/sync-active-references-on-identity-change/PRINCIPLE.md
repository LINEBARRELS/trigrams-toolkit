# 变更资源身份时同步现行引用并保留历史事实

移动知识文件、调整 `principle` 的 `scope` 或目录名、或变更 `workbook` 位置时，应同步全部现行引用并明确在途工作的承接范围。

身份变更与引用维护应遵循以下要求：
- `principle` 修改 `scope` 或英文目录名会改变派生 ID，应同步更新当前 `workbook`、文稿引用、分类查询与安装入口；仅修改中文标题或 `description` 不改变身份。
- `workbook` 调整目录时应通过 YAML 头的显式 `resourceId` 保留已被外部引用的身份；原先省略显式 ID 的条目在改名时应先写入原 ID。
- 替代或特化既有规则时，应在正文写明适用对象、条件与保留的上级要求。
- 已完成或归档的历史记录应保留当时的原始资源身份与路径事实，不应逆向篡改历史证据。
