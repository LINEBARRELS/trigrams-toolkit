# 变更资源身份时同步现行引用并保留历史事实

移动知识文件、调整 `principle` 的 `scope` 或目录名、或变更 `workbook` 位置时，应同步全部现行引用并明确在途工作的承接范围。

身份变更与引用维护应遵循以下要求：
- `principle` 修改 `scope` 或英文目录名会改变派生 `resourceId`，应同步更新现行 `workbook` `includes`、规则槽位引用、`README.md`、Setup 入口及关联测试断言；仅修改中文标题或 `description` 不改变身份。
- `workbook` 调整目录时，应通过 YAML 头的显式 `resourceId` 保留外部引用身份；原省略显式 ID 的条目改名时先补写原 ID。
- 替代或特化既有规则时，应在正文写明适用对象、条件与保留的上级要求。
- 已完成或归档的历史记录应保留当时的原始身份与路径事实，不应逆向篡改。
