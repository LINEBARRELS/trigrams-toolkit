# 保持引用链可达与分支完整

资源引用、条件分流与跨能力依赖应在目标部署环境中可达，并完整覆盖当前工作所需的模式与分支。

核对引用关系时应满足以下要求：
- 目标、验收与必要边界在入口或适用依赖中有明确定义；仅存在文件但缺少可达入口，或只提能力名称而未说明输入与用途，不能视为已覆盖。
- 读取条件应能准确选到当前分支所需的执行要求、模板或背景资料；消除无实质责任的空转转引文件与循环依赖。
- 引用路径与工具入口应能在安装后的目标环境中直接定位，不依赖未声明的维护源路径、相邻 Skill 私有文件或隐含父目录。
- 上游依赖已声明的规则不在调用方重复补写；依赖不可读时应标明未验证范围。
