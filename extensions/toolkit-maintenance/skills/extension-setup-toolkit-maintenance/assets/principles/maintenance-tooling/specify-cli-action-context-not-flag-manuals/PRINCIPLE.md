# 按动作契约声明 CLI 调用并由帮助自解释参数

Skill、`workbook` 与配套说明在声明使用 CLI 时，应只提供完成当前动作所需的核心调用契约，将详细参数留给命令行帮助自解释。

调用说明应包含以下核心信息：
- **用途与时机**：说明调用步骤与目标产出，上下文明确时保持精练。
- **调用形式**：写明实际命令、必要参数与工作目录前提；全局工具使用公共命令名，私有脚本写明解释器与相对资源根的入口路径，不应硬编码宿主固定路径。
- **输入与结果**：说明参数值及关键字段来源（可直接引用上游响应），明确成功判据（退出码与 `ok`）、后续消费的返回值及异常分支处理。

清晰区分同名 Skill 能力与 CLI 命令；完整选项与默认值通过 `<工具> <子命令> --help` 查询，不在文稿中复制参数手册。
