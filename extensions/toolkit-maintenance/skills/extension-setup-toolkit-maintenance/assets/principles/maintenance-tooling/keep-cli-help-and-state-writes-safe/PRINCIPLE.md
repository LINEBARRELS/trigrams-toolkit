# 保证 CLI 分层帮助无副作用且状态写入可恢复

面向 Agent 的自有 CLI（含全局工具与私有脚本）应提供独立、无副作用的分层帮助，并对所有状态写入提供预览、归属保护与中断恢复能力。

帮助与状态操作应满足以下要求：
- 根命令、命令组和叶子命令均应支持等价的 `-h`、`--help`；根与命令组列出可用子命令，叶子帮助说明用途、必要参数、默认值、输入输出结构与关键错误。
- 帮助命令应独立于业务输入、凭据检查、项目初始化状态与业务锁，在空配置下仍以退出码 0 正常输出且不产生任何写入副作用；帮助行为应通过实际执行命令核验。
- 安装、升级、同步与移除等状态写入应分别记录预览、写入与验证结果，保留来源、目标归属与本地修改保护；中断后应能核对已写入状态并按原操作安全恢复。
