# 区分全局公共 CLI 与私有脚本的归属及安装边界

工具应按职责边界划分为全局公共 CLI、项目工具与资源私有脚本，并与所在资源清单或 `extension.json` 声明保持一致。

归属与安装审核应满足以下要求：
- 共享状态与生命周期通过统一安装的全局公共 CLI 维护，不向项目复制公共工具；单资源辅助脚本留在所属 Skill 或 `workbook` 内部。
- 完整 Skill 由包管理器按范围安装并自包含入口、私有资料与脚本；项目扩展资源与声明材料按快照装配并受内容基线保护。
- 实际存在的文件与导出资源应与 `assets/extension.json`（或项目 `docs/resources.json`）的 `resourceRoots`、`install` 声明一致，不出现越界引用或未受保护覆盖。
